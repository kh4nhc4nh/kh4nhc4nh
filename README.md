## 🚀 Featured Projects

### 🔬 1. Malware Analysis Platforms & Specialized Tooling

#### 📑 [PDF Static Advanced Security Analyzer (`pdf_analysts`)](https://github.com/kh4nhc4nh/pdf_analysts)
A dedicated, isolated static analysis engine for malicious and weaponized PDFs.
- **Key Capabilities:** Zero-execution isolation on Ubuntu, QPDF object-graph reconstruction, deobfuscation (Octal/Base64/Hex stream decoding), YARA & ClamAV scanning, and embedded file extraction.
- **Dual-Tier Reporting:** Generates condensed JSON (91.7% noise reduction) and professional 2-page vector PDF reports structured specifically for both **Non-Technical Management** (Executive risk summary) and **SOC Analysts** (Exact Object IDs, Catalog reference paths, trigger mechanisms, and IR playbooks).
- ➡️ [View Repository](https://github.com/kh4nhc4nh/pdf_analysts)
